## Short launch post

I built **Global LLM Atlas**, an open dataset and interactive map of publicly accessible conversational LLM/MLLM services around the world.

Instead of another generic AI-tools list, the project tracks country/project association, registration, capabilities, lifecycle status, provenance and manual verification. The canonical dataset is available as JSON and CSV, and automated URL checks never silently override human/semantic review.

Explore: https://renzo-bd.github.io/global-llm-atlas/
Repository: https://github.com/Renzo-BD/global-llm-atlas

I would especially value contributions for countries that are still missing, corrections to country attribution, and better primary-source evidence. If the project is useful, a GitHub star helps others find it.

## Hacker News draft

**Title:** Show HN: Global LLM Atlas – mapping public conversational AI by country

I’m building Global LLM Atlas, an open and versioned dataset of public conversational LLM/MLLM web experiences around the world.

The motivation was that most AI directories are product lists, while I wanted something that could be audited and reused as data. Each entry can track country association, operator country, service type, registration, capabilities, lifecycle status, confidence and provenance. The project exposes canonical JSON, CSV and JSON Schema plus an interactive map.

A weekly checker tests basic reachability, but deliberately cannot change canonical status automatically: HTTP 200 is not evidence that a chatbot is actually usable.

The current release is a conservative seed, and the next phase is systematic country expansion. Feedback on the data model, attribution methodology and missing national AI services would be very useful.

Repo: https://github.com/Renzo-BD/global-llm-atlas
Atlas: https://renzo-bd.github.io/global-llm-atlas/

## LinkedIn draft

🌐 **Global LLM Atlas: mapping conversational AI beyond the usual names**

I’m developing an open, curated and versioned atlas of publicly accessible conversational LLM/MLLM services around the world.

The project combines an interactive world view with reusable JSON/CSV data and an evidence-oriented curation model. It tracks not only the service link, but also country/project association, operator jurisdiction where known, registration, selected capabilities, lifecycle status, confidence and provenance.

One design principle matters especially to me: **a reachable URL is not automatically a working AI service**. Automated checks therefore flag potential changes for review instead of silently rewriting the dataset.

The next stage is systematic global expansion, especially countries that are poorly represented in mainstream AI directories.

## Outreach principles

1. Post where the project is genuinely relevant; do not mass-spam communities.
2. Lead with the useful artifact or research question, not with a request for stars.
3. Ask for missing-country contributions and corrections; participation creates durable interest.
4. Respond quickly and substantively to issues and comments after launch.
5. Use the same canonical project URLs so backlinks accumulate around one repository/site.
6. Never buy, exchange, automate or coordinate fake stars.
