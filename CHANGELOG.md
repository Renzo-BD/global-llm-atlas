## [0.1.0] - 2026-09-10

### Added
- Initial curated seed with 57 working public conversational AI access points across 25 countries.
- JSON canonical dataset and CSV export.
- Interactive filterable atlas with world map.
- Weekly automated reachability checker.
- Conservative outage-report workflow that requires human confirmation.
- Contribution guide, issue templates, status vocabulary and coverage report.

### Scope
- Imported only entries contained in the curator-provided HTML bookmark export.
- Explicitly excluded the `MULTI MODELOS` folder.
- All seed entries were recorded as manually working on 2026-09-10.
